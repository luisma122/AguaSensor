ASÍ TRABAJA

¿Cómo funciona AguaSensor?

El sensor mide el nivel del agua y transmite la información a un sistema de control o monitoreo compatible.

  1. 1

    Detecta el nivel

    El sensor realiza la medición dentro del tanque.

  2. 2

    Procesa la información

    El sistema convierte la medición en un dato que puede interpretarse.

  3. 3

    Envía los datos

    La información llega al sistema de control o monitoreo.

  4. 4

    Permite actuar

    Se puede visualizar el nivel y generar alertas según la configuración.
