AGUASENSOR - ARCHIVOS DEL SITIO WEB

Archivos:
- index.html: estructura de la página.
- styles.css: colores, diseño y adaptación a celulares.
- script.js: menú móvil y simulador visual del nivel.
- referencia-sensor.png: imagen que compartiste y que se usa como ilustración.

PARA PROBARLO:
1. Descomprime la carpeta.
2. Abre index.html en tu navegador.

PARA SUBIRLO A GITHUB:
1. Crea un repositorio.
2. Sube TODOS estos archivos a la raíz del repositorio.
3. En GitHub entra a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Elige la rama main y la carpeta /(root), y pulsa Save.

NOTA:
El indicador de nivel es una demostración visual; no está conectado a un sensor físico.
El correo de contacto es de ejemplo y puedes cambiarlo en index.html.
