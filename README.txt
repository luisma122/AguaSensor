AGUASENSOR - SITIO WEB ACTUALIZADO

Esta versión replica las secciones de las referencias visuales:
- Proceso de funcionamiento en cuatro tarjetas.
- Formulario de demostración/piloto de 30 días.
- Simulador interactivo del tanque con aviso de ejemplo estilo WhatsApp.
- Planes Básico, Plus y Compra de equipo.
- Contacto con los dos números de WhatsApp.

Archivos:
- index.html
- styles.css
- script.js
- referencia-sensor.png

NÚMEROS DE WHATSAPP:
- 310 658 9313
- 305 226 1783

Al enviar el formulario, aparece una selección para elegir a cuál número enviar el mensaje preparado con los datos ingresados.

PARA VER LA PÁGINA:
Abre index.html en un navegador. Mantén todos los archivos en la misma carpeta.

PARA PUBLICAR EN GITHUB PAGES:
1. Sube TODOS los archivos a la raíz del repositorio.
2. En GitHub abre Settings > Pages.
3. En Build and deployment selecciona Deploy from a branch.
4. Selecciona la rama main y la carpeta /(root), luego Save.

NOTA IMPORTANTE:
El simulador y el mensaje de WhatsApp son demostrativos. El nivel de agua no se está leyendo desde un sensor físico ni se envían alertas reales automáticamente.
Los datos del formulario se incluyen en el mensaje de WhatsApp y el usuario debe pulsar Enviar dentro de WhatsApp.

La sección demostrativa muestra un tanque vertical con nivel de agua ajustable, junto a la explicación de cómo funciona AguaSensor.
