# AguaSensor

Sitio web estático de presentación para AguaSensor.

## Publicar con GitHub Pages

1. Crea un repositorio público llamado `AguaSensor`.
2. Sube `index.html` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama **main** y la carpeta **/(root)**. Guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección aparecerá en esa misma sección.

## Nota
El formulario prepara un mensaje y abre WhatsApp; no guarda datos en un servidor. El panel y el simulador son demostrativos. Verifica precios, disponibilidad, cobertura y características antes de ofrecerlos comercialmente.
